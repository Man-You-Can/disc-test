守護者（DISC S 型）

穩健型

你帶來穩定：信守承諾，有始有終，支持他人，化解衝突。可預期、信任，以及適應變化所需的時間，對你來說很重要。

與相近類型的差別

守護者是純粹的 S 型：最重要的是穩定和關係。外交家（SI）的沉穩搭配了善於交際，職人（SC）搭配了對規則的重視，執行者（SD）搭配了追求目標的韌性。守護者則守在中間：不衝在前面，不求關注，也不建立體系，只是讓一切順利運作，讓人覺得可靠安心。和專家（CS）、引路人（IS）相比，守護者的不同在於：穩定比精準和交流都更重要。

工作中的守護者

在職場上，守護者往往不太顯眼，直到休假時大家才發現少了什麼。守護者記得誰答應過什麼，幫助新人，回答沒人想處理的問題，把別人早已忘記的專案做完。最適合的環境是流程清楚、團隊穩定、以可靠而不是速度來衡量成果。頻繁的組織調整和「救火模式」的工作，會讓守護者筋疲力盡。

適合的角色與任務

  • 客戶服務與支援
  • 協調人員、專案助理
  • 職場導師、教師
  • 醫療、社會工作、照護
  • 流程固定的營運與服務類職務

在團隊中

這是可以託付的人：把事情做到底，記得每一項約定，幫助新人，也化解衝突。常常在旁人不易察覺的地方把團隊凝聚在一起。風險在於得不到應有的肯定，還會因為不懂得拒絕而被別人的工作壓垮。

擔任主管的守護者

當上主管的守護者細心又公正：了解每一位部屬，保護團隊，在困難時不會丟下大家不管。這樣的團隊人員流動率低，氣氛平和。弱點是：拖延不受歡迎的決定，很少給出嚴厲的回饋，還會把部屬的工作攬到自己身上，只為了不讓大家負擔太重。

需要什麼樣的主管

守護者需要的主管，會提前告知變動、解釋原因，並給時間適應。守護者重視平和的語氣、清楚的期望，以及對幕後工作的感謝。突然轉向、大吼和當眾施壓，會長期破壞守護者的信任，即使守護者什麼都沒說。

壓力與衝突之下

在壓力下，守護者會放慢腳步、變得沉默。為了不起爭執而同意，承擔更多工作，把不滿累積在心裡，旁人卻看不出來。起衝突時會避開或讓步；如果壓力持續很久，可能出乎所有人意料地堅持不讓，或者遞出辭呈——看似「突然」，其實守護者早就下定決心了。

可以加強的地方

  • 已經負擔過重時，對新任務說「不」
  • 有不同意見，趁分歧還小的時候就說出來
  • 用小步驟嘗試新事物，不必等到完全有把握
  • 主動讓人知道自己的成果，不要等別人自己發現

如何與其他風格溝通

與支配型（D）

有不同意見就當場說，而且要簡短；主動要求清楚的優先順序，不要用猜的。

與影響型（I）

明確說出自己的界線，並請對方拿出計畫。對你來說，光有想法是不夠的。

與穩健型（S）

互相訂下期限，並輪流擔任拍板的那個人。

與謹慎型（C）

把對方的意見理解成對品質的在意；想改變什麼，就拆成小步驟來提。

如何與這類人達成共識

和守護者談事情要平和，而且要提早。說明哪些要改變、為什麼，哪些維持不變，以及你會怎麼支援。不要要求當場回答：給一天時間考慮，並私下詢問意見，而不是在全員會議上問。守護者想過之後說的「好」，比在壓力下脫口而出的「好」可靠得多。

實際案例

公司改用新的帳務系統。守護者默默利用晚上學會，還幫同事上手，從不抱怨。一個月後才發現，守護者一個人做著一個半人的工作，而且打算離職。如果主管早點問一句「換系統還順利嗎？有什麼卡住的地方？」，就能在辭呈送出前三週發現問題。
