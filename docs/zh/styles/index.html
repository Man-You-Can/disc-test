DISC 四种性格类型：支配型、影响型、稳健型、谨慎型

DISC 从四个维度描述行为。每个人都具备这四种风格，只是其中一两种更突出。下面介绍每种风格的典型特征、动机来源，以及与之沟通的最佳方式。在中文资料里，这四种风格也常被粗略地类比为 PDP 测试中的老虎、孔雀、考拉和猫头鹰。

D支配型 · 成就者

结果与掌控

你直奔目标、行动迅速：主动出击，不经冗长讨论就做决定，也不畏惧阻力。掌控局面、看到可衡量的成果对你很重要。

直率果断结果导向独立自主要求高

优势

  • 你决策迅速，并勇于为决定负责
  • 你在危机中不慌乱，在他人犹豫时果断行动
  • 你设定远大目标并全力达成
  • 你说话直截了当，毫不含糊

成长空间

  • 对节奏较慢或较谨慎的人缺乏耐心
  • 倾向于强行推动决定，不愿听取其他方案
  • 言辞生硬，容易让人感到压力

什么能激励你

  • 决策权和影响事态走向的机会
  • 有难度的任务与挑战
  • 不被事无巨细地管着
  • 可衡量的成果与胜利

什么样的沟通对你最有效

  • 简短直接、直奔要点的沟通：结果、期限、方案
  • 不绕弯子，也没有冗长的开场白
  • 几个可选方案，而不是现成答案——你更想自己拿主意
  • 以事实而非情绪为依据的讨论

压力之下

在压力之下，你会变得更强硬、更缺乏耐心：打断别人、事事亲力亲为、为了速度绕开规则。明确的授权和独立行动的空间会有所帮助。

理想的工作环境

充满活力、高度自主的环境，目标清晰，努力与成果直接挂钩。一成不变的例行工作和严密管控会打击积极性。

I影响型 · 鼓舞者

人际与热情

你靠人际关系推动事情：轻松与人结识，用热情感染他人，以言语和情绪打动人心。认可和生动的交流对你很重要，而繁文缛节和例行公事很快会让你感到疲惫。

善于交际乐观热情奔放有说服力随性

优势

  • 你很容易与人建立联系并赢得好感
  • 你能鼓舞和激励团队
  • 你点子多，在别人看到问题的地方看到机会
  • 你在困境中依然保持乐观

成长空间

  • 一时兴起许下的承诺，事后难以兑现
  • 对细节和期限关注不足
  • 倾向于说得多、听得少

什么能激励你

  • 认可与赞许
  • 交流与团队协作
  • 自由表达的空间
  • 新鲜感和多样化的任务

什么样的沟通对你最有效

  • 先聊几句、拉近关系，再谈正事
  • 有发言和讨论想法的空间
  • 你的贡献得到公开的肯定
  • 约定有书面记录——这对双方都有好处

压力之下

在压力之下，你会变得心神不定、冲动行事，回避不愉快的谈话，并可能把形势想得过于乐观。开诚布公的讨论和同事的支持会有所帮助。

理想的工作环境

开放、友好、充满交流与认可、不受僵化规章束缚的环境。孤立和单调会消磨热情。

S稳健型 · 守护者

支持与稳定

你带来稳定：信守承诺，善始善终，支持他人，化解冲突。可预期、信任，以及适应变化的时间对你很重要。

有耐心可靠沉稳关心他人始终如一

优势

  • 你经得起时间考验，值得长期信赖
  • 你善于倾听和支持他人
  • 你工作耐心、有条不紊
  • 你能凝聚团队、化解冲突

成长空间

  • 抗拒变化，即使是有益的变化
  • 难以拒绝他人和坚持自己的立场
  • 为了维持和气而隐藏不同意见

什么能激励你

  • 稳定与可预期
  • 对贡献的真诚感谢
  • 清晰的期望和游戏规则
  • 在团结的团队中工作

什么样的沟通对你最有效

  • 变化提前告知，并讲清为什么要变
  • 有人直接问你的意见——你很少主动说出来
  • 没有压力，也有时间从容作答
  • 对你具体付出的真诚感谢

压力之下

在压力之下，你会封闭自己、变得过于迁就，并推迟做决定。突如其来的变化和公开的冲突尤其难以承受。给予适应的时间和心平气和的交谈会有所帮助。

理想的工作环境

稳定的环境，流程清晰、关系融洽、变化节奏合理。混乱、频繁切换和激烈竞争会让人身心俱疲。

详细了解“守护者”类型

C谨慎型 · 分析家

精准与质量

你依据事实和标准行事：核查、分析、规划，不喜欢仓促的决定。对你而言，质量和正确比速度和表面效果更重要。

精确善于分析谨慎有条理内敛

优势

  • 工作质量高，注重细节
  • 判断客观、有逻辑
  • 善于预判风险和制定计划
  • 自律并信守约定

成长空间

  • 追求完美，为了理想状态拖延期限
  • 对自己和他人过于苛刻
  • 沉溺于分析而迟迟不行动

什么能激励你

  • 明确的标准和质量准则
  • 分析和准备的时间
  • 对专业能力的认可
  • 有逻辑、有依据的决策

什么样的沟通对你最有效

  • 事先准备好的事实、数据和论据
  • 有思考的时间，而不是被要求立刻答复
  • 对流程和既定约定的尊重
  • 具体、就事论事、不带情绪的批评

压力之下

在压力之下，你会退回自己的世界，变得过分挑剔，并陷入细节。不得不在缺乏数据的情况下行动会让你烦躁。清晰的标准和核对的时间会有所帮助。

理想的工作环境

结构清晰的环境，有明确的标准、充分的信息和专注工作的条件。不确定性、仓促和情绪化的施压会降低效率。

DISC 的 16 种性格类型

D成就者D · 支配型

你直奔目标、行动迅速：主动出击，不经冗长讨论就做决定，也不畏惧阻力。掌控局面、看到可衡量的成果对你很重要。

DI开拓者DI · 支配型 + 影响型

干劲与魅力：你能迅速带领大家奔向目标，并善于让人追随。你以魄力和热情说服他人，边走边做决定，但对细节的耐心和审慎往往不足。

DC战略家DC · 支配型 + 谨慎型

以质量赢得结果：你对自己和他人要求严格，思维系统化，没有充分论据绝不做决定。你擅长复杂任务，但可能显得冷淡和过于挑剔。

DS实干家DS · 支配型 + 稳健型

坚持与可靠：你执着地朝目标前进，却不张扬，而且善始善终。你同时看重自主与稳定，这是难得的组合。

I鼓舞者I · 影响型

你靠人际关系推动事情：轻松与人结识，用热情感染他人，以言语和情绪打动人心。认可和生动的交流对你很重要，而繁文缛节和例行公事很快会让你感到疲惫。

ID激励者ID · 影响型 + 支配型

能量与冲劲：你用想法感染他人，勇于主动出击。你善于“推销”想法和目标，但有高估自身实力、低估细节的风险。

IS引路人IS · 影响型 + 稳健型

温暖与投入：你让人愿意亲近，善于支持和凝聚他人。关系和氛围对你很重要，而冲突和苛刻的要求会让你感到吃力。

IC演说家IC · 影响型 + 谨慎型

口才与精准：你能有说服力地阐述一个深思熟虑的立场。你把善于交际与注重事实结合在一起，但可能在随性与谨慎之间摇摆。

S守护者S · 稳健型

你带来稳定：信守承诺，善始善终，支持他人，化解冲突。可预期、信任，以及适应变化的时间对你很重要。

SI外交家SI · 稳健型 + 影响型

平和与友善：你营造信任的氛围，化解棱角，支持团队。对你来说，说“不”和坚持不受欢迎的决定并不容易。

SC匠人SC · 稳健型 + 谨慎型

可靠与细致：你有条不紊地工作，遵守规则，不慌不忙地把事情做完。你看重稳定和明确的期望，而突变和施压会让你难以承受。

SD执行者SD · 稳健型 + 支配型

执着与耐心：你沉着而坚定地推动事情走向结果，不在多余的讨论上耗费精力。长期来看你非常可靠，只是在旁人眼中可能显得固执。

C分析家C · 谨慎型

你依据事实和标准行事：核查、分析、规划，不喜欢仓促的决定。对你而言，质量和正确比速度和表面效果更重要。

CD把关人CD · 谨慎型 + 支配型

标准与意志：你要求自己和他人都做到精确，能迅速发现错误，并敢于指出。你擅长复杂的专业任务，但可能过于严苛和封闭。

CS专家CS · 谨慎型 + 稳健型

精确与一贯：你工作深思熟虑，核对细节，依靠经过验证的方法。你是可靠的专业人士，只是不确定性和急速变化会让你感到吃力。

CI顾问CI · 谨慎型 + 影响型

分析与沟通：你既能把问题弄明白，又能把它通俗易懂地讲给别人听。这是难得的组合：下结论时审慎，交流时轻松。有时“先核实”与“先分享”之间的内心拉扯会成为阻碍。
