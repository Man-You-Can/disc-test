DISC 测试结果分析

DISC 测试的结果不是一个字母，而是一张有三条线的图表、四种风格的百分比，以及一个由一到两个字母组成的类型。下面用示例说明报告中每一部分的含义，以及解读时如何避免出错。

还没有自己的结果？来做个测试吧：约 10 分钟，免费。

结果由哪些部分组成

完成最后一组题后，你会看到四个部分：带一个或两个字母的类型名称（例如“开拓者，DI”）、一张有三条线的图表、四条带百分比的横条，以及文字描述：关键特质、优势、成长空间、动机、压力之下的表现，还有如何与你沟通更有效的建议。同一份报告也可以发送到你的邮箱，或通过链接打开。

报告中的所有数字都来自你在 24 组题中的勾选。每一组里，你都选出一条“最像”自己的陈述和一条“最不像”自己的陈述，而每条陈述都对应 D、I、S、C 四种风格中的一种。因此每种风格都有两个数字：被选为“最像”的次数，和被选为“最不像”的次数。

图表的三条线

综合风格（带彩色圆点的粗线）是最主要的一条。它是每种风格“最像”与“最不像”勾选数之差，换算到 0 至 24 的标尺上。标尺的中点是 12，在图上用虚线标出。高于中线的风格视为明显，低于中线的则表现较弱。

外在形象是按“最像”勾选画出的线。它代表你在工作中努力表现出的样子，是你有意维持的形象。本真自我是按“最不像”勾选反向画出的线：你越少否定某种风格，这条线在该风格上的点就越高。它更接近你不费力气、“下意识”时的行为，例如在压力之下或陌生情境中的表现。

如果三条线彼此重合，说明你在任何场合的表现都大致相同。如果外在形象和本真自我出现分歧，这并不是问题，而是一个提示：某种风格是你靠意志力调动出来的。这通常意味着，你的角色要求一种对你来说并不自然的行为方式，而维持它需要消耗能量。

主导风格与次要风格

主导风格就是综合得分最高的那一种。它是类型的第一个字母，也是整份描述的基础。次要风格的成立条件是：它的得分为正，且不低于主导风格的 40%（在 −24 到 +24 的原始分中至少 3 分）。它会成为第二个字母，并给描述增添一层色彩：D 加次要 I（DI）靠气势和热情说服他人，D 加次要 C（DC）则靠高标准和论据。

字母的顺序很重要：DI 和 ID 是不同的类型。DI 的主导风格是支配型，影响型起辅助作用；ID 的人首先是善于交际、能鼓舞他人的，气势只在必要时才拿出来。如果第二种风格的得分为负，或者明显低于主导风格，类型就保持“单一”：D、I、S 或 C。

开拓者 (DI)

D支配型79%
I影响型67%
S稳健型25%
C谨慎型29%

综合风格在 D 和 I 上很高，在 S 和 C 上很低。主导风格是支配型（D），影响型（I）也很突出并被计为次要风格：类型 DI，“开拓者”。这样的人决策迅速、能带动他人，但往往缺少对细节的耐心和必要的谨慎。

四项得分都接近中线。主导风格仍按最高分形式上确定，但报告会指出这属于均衡型。多半说明这个人会根据情境灵活切换风格；如果作答时不太确定，建议重新测一次。

百分比代表什么

四条横条上的百分比就是同一个综合得分，换算到 0 至 100 的量表：−24 对应 0%，0 对应 50%，+24 对应 100%。高于 50% 说明这种风格你选择的次数多于否定的次数；低于 50% 则相反。它不是“我身上有百分之多少的 D”，而是衡量与其余三种风格相比，这种风格对你有多典型。

四种风格原始分之和永远为零，因为测试比较的是各风格之间的相对高低，而不是分别测量它们。因此某一种风格得分高，就必然意味着另一种风格得分低。通常互为对立的是 D 与 S，或者 I 与 C：它们分别位于节奏轴和关注点轴的两端。

均衡型

如果没有任何一项得分明显高于中线，报告会把你的类型称为均衡型，同时仍按最高分标出主导风格。这样的结果多半意味着灵活：你会根据情境在不同风格之间切换，不同风格的同事和你相处都同样自在。

较少见的情况是，平坦的图表说明你作答时不太确定、想得太久，或者试图挑“正确”的答案。验证很简单：过几天再测一次，作答时快一些，并想着一个具体的工作角色。如果结果依然平坦，那么灵活本身就是你的特点。

拿到结果之后做什么

先从优势和成长空间的描述开始：标出哪些你认得出来，哪些看起来不太准确。接着读一读“什么样的沟通对你最有效”这一节，想想同事们是否了解这些。结果最有价值的用法是引发对话：在风格搭配页面上和团队成员比较各自的类型，并商定如何照顾彼此的差异。

类型不是判决书，也不是天花板。它描述的是你当下的习惯行为，随着新的角色、经验和处境的变化，它也可能移动。建议保存报告链接，一年后再测一次，两次结果的差异会显示工作对你产生了怎样的影响。

解读结果时的常见误区

  • 认为某一种风格“更好”。每种风格都有优势，也都有代价：D 的强势会变成缺乏耐心，C 的严谨会变成拖延工期。
  • 弄混字母的顺序。DI 和 ID、SC 和 CS 是主导风格不同的类型。
  • 把百分比当成成分比例。D 为 70% 并不表示“我有 70% 是支配型”，而是说明 D 风格你选择的次数明显多于否定的次数。
  • 由此推断能力高低。DISC 描述的是行为风格，而不是能力、智力或是否胜任某个岗位。
  • 凭别人的结果去评判一个人。报告是自我评估，本人最清楚描述哪里说中了、哪里没有。
