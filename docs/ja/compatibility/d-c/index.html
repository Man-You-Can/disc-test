主導と慎重の相性

D · C

どちらも課題と成果に向かいますが、Dは速く、Cは正しくを望みます。テンポを取り決めれば、難しいプロジェクトで力を発揮する組み合わせです。

DとCは課題への集中を共有しています。どちらも雰囲気より仕事を重んじ、能力を尊重し、社交的な雑談に時間を使いません。違いはテンポです。Dはデータが半分そろえば決断し、Cはすべて集めて検証したがります。DはCを足を引っぱる心配性だと考え、CはDを無責任だと考えます。難しいプロジェクトでは、これが最良の組み合わせです。Dが前進を確保し、Cが品質とミスからの防御を担います。鍵は、どこでスピードが必要で、どこで正確さが必要かをあらかじめ決めておくことです。

共通点

  • 関係よりも課題と成果に集中すること
  • 能力と論理への敬意
  • 率直さ：どちらも感情より事実を選ぶ

摩擦が起きやすいところ

  • Dは素早く決め、Cはデータと時間を求める
  • Cは押しの強さを圧力と受け取り、Dは慎重さをサボタージュと受け取る
  • どちらも批判的で、評価の言葉を惜しむ

主導（D）へのアドバイス

  • Cに分析の時間を与え、いつ答えが必要かを前もって伝えること
  • 決定は「自分がそう言ったから」ではなく事実で裏づけること
  • 仕事を分けること。ミスの代償が大きい領域では、最終判断はCに委ねましょう

慎重（C）へのアドバイス

  • 「後で完璧に」ではなく「今、十分に良い」という案をDに示すこと
  • リスクは短く、影響の見積もりを添えて伝え、長い根拠づけは省くこと
  • Dからの称賛を期待しないこと。批判がないこと自体が彼の承認です

DDD + D主導

決めること、引っぱることに慣れた二人。一緒だと物事が速く進みますが、主導権を争い、めったに譲りません。

DI主導 + 感化D · I

最もエネルギッシュなペア。Dが目標とテンポを決め、Iが人を巻き込みます。一緒にプロジェクトを立ち上げますが、細部と慎重さを軽く見がちです。

DS主導 + 安定D · S

両方の軸で正反対。Dは速く成果を目指し、Sは落ち着いて関係を大切にします。最も難しく、そして最も有益なペアの一つです。

III + I感化

人とアイデアと注目を好む二人。一緒にいると楽しく気楽ですが、期限と細部を見る人が必要です。

IS感化 + 安定I · S

温かく友好的なペア。Iが励まし、Sが支えます。雰囲気づくりや顧客対応には向きますが、厳しい決断は苦手です。

IC感化 + 慎重I · C

正反対の組み合わせ。Iは人と印象に生き、Cは事実と正確さに生きます。難しいペアですが、信頼が育てば強くなります。

SSS + S安定

最も穏やかなペア。信頼性、忍耐、支え合いがあります。危険なのは停滞と、難しい話題を持ち出せないことです。

SC安定 + 慎重S · C

落ち着いて地に足のついたペア。Sが関係を保ち、Cが品質を守ります。運用やプロセスには最適ですが、変化には苦労します。

CCC + C慎重

専門家同士のペア。正確さ、論理、高い基準があります。一緒だと非の打ちどころのない仕事をしますが、時間がかかり、細部で議論しがちです。
