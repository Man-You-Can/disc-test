# Тест DISC — мультиязычный статический сайт

Бесплатный онлайн-тест поведенческих стилей DISC на 10 языках. Полностью статический: результат считается в браузере, сервер и база данных не нужны, ответы никуда не отправляются.

**Языки:** English, Русский, Español, 简体中文, العربية, Português, Français, Deutsch, 日本語, हिन्दी.

## Структура

```
site.config.json      адрес сайта, список языков, e-mail для кнопки «Отправить по почте», свой домен
src/template.html     шаблон страницы теста (вёрстка + логика), общий для всех языков
src/root.html         корневая страница: определяет язык браузера и перенаправляет на /xx/
src/404.html          страница «не найдено» (перенаправляет на главную)
src/locales/xx.json   все тексты одного языка (ru.json — эталон)
build.js              сборка: src → docs/
scripts/validate-locale.js  проверка, что локаль структурно совпадает с ru.json
scripts/serve.js      локальный просмотр собранного сайта
docs/                 готовый сайт (это и публикуется на GitHub Pages)
disc-test/index.html  исходная одноязычная версия (для истории)
```

## Как собрать

```bash
node build.js            # пересобирает docs/ для всех языков из site.config.json
node scripts/serve.js    # открыть http://localhost:8765 для проверки
```

После сборки закоммитьте изменения в `docs/` и запушьте в `main` — GitHub Pages опубликует их автоматически (обычно за 1–2 минуты).

## Как изменить тексты

Все тексты живут в `src/locales/<язык>.json`. Меняйте значения, не меняя ключи. Затем:

```bash
node scripts/validate-locale.js   # проверит все локали против ru.json
node build.js
```

**Важно:** порядок стилей в 24 блоках вопросов (`BLOCK_KEYS` в `src/template.html`) менять нельзя — от него зависят коды результатов, которые уже разосланы участникам.

## Как добавить язык

1. Скопируйте `src/locales/en.json` в `src/locales/<код>.json`, переведите, укажите `lang`, `name`, `dir` (`rtl` для арабского/иврита) и `dateLocale`.
2. Добавьте код в `languages` в `site.config.json`. Если нужны особые шрифты (не латиница/кириллица), добавьте запись в `FONTS` в `build.js`.
3. `node scripts/validate-locale.js <код>.json && node build.js`.

## Свой домен

1. В `site.config.json` укажите `"siteUrl": "https://ваш-домен.com"` и `"customDomain": "ваш-домен.com"` — сборка создаст файл `docs/CNAME` и правильные canonical/hreflang.
2. У регистратора домена создайте запись `CNAME` для `www` (или поддомена) на `man-you-can.github.io`, а для корневого домена — записи `A` на адреса GitHub Pages: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
3. В настройках репозитория (Settings → Pages) введите домен и включите «Enforce HTTPS».
4. `node build.js`, коммит, пуш.

## Результаты участников

Участник на экране результата получает ссылку вида `…/ru/#r=DISC1.…` и код. Ссылка открывает отчёт на любом языке. Кнопка «Отправить по почте» открывает почтовый клиент; чтобы письма приходили на конкретный адрес, укажите его в `contactEmail` в `site.config.json` и пересоберите.

Панель администратора (`…/ru/#admin` или ссылка в подвале) собирает вставленные коды/ссылки в таблицу и экспортирует её для Excel. Таблица хранится в браузере администратора.
