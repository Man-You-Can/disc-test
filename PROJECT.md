# Тест DISC — описание проекта и журнал работ

> Этот файл — краткая «карта» проекта: что это, как устроено, что уже сделано и что осталось.
> Обновляется при каждом изменении проекта. Техническая инструкция по сборке — в [README.md](README.md).

## Что это

Бесплатный онлайн-тест поведенческих стилей DISC (Dominance, Influence, Steadiness, Conscientiousness).
Участник отвечает на 24 блока по 4 утверждения (в каждом отмечает «больше всего похоже на меня» и «меньше всего»),
получает ведущий и вторичный стиль, график, описание сильных сторон, зон роста, мотивации, поведения под стрессом
и рекомендации, как с ним общаться. Всего 16 итоговых профилей (4 «чистых» + 12 сочетаний).

Тест открыт для всех, без регистрации, на 10 языках. Результат считается в браузере и никуда не отправляется.

Корневой адрес показывает список всех языков; язык браузера (или ранее выбранный) подсвечивается и предлагается кнопкой «Продолжить». Автоматического перенаправления нет, чтобы поисковики видели все версии.
Ссылка на конкретный результат имеет вид `…/ru/#r=DISC1.…` и открывается на любом языке.

## Как устроено

- **Статический сайт**: HTML + CSS + JS, без базы данных. Хостинг бесплатный. Единственная серверная часть — скрипт Google Apps Script, который отправляет участнику письмо с результатом.
- **Один шаблон на все языки**: `src/template.html` содержит вёрстку и логику; тексты подставляются из `src/locales/<язык>.json` при сборке (`node build.js` → `docs/`).
- **Эталон текстов — `src/locales/ru.json`**. Скрипт `scripts/validate-locale.js` проверяет, что каждая локаль структурно совпадает с эталоном (ключи, длины массивов, плейсхолдеры `{n}`, теги `<b>`/`<br>`).
- **Подсчёт результата**: по каждому стилю считается «больше» минус «меньше» (от −24 до +24). Ведущий стиль — максимум; вторичный засчитывается, если он положительный и не меньше 40 % от ведущего (минимум 3). Порядок утверждений в блоках (`BLOCK_KEYS` в шаблоне) менять нельзя: от него зависят коды результатов.
- **Хранение**: прогресс, последний результат, выбранный язык и отметка о прочтении уведомления о cookie — в `localStorage` браузера участника. Имя и e-mail входят в код результата. Само уведомление показывается внизу страницы до нажатия «Понятно». Панель администратора (`#admin`) хранит вставленные коды тоже локально, в браузере администратора, и умеет экспортировать таблицу для Excel.
- **Локализация вёрстки**: арабская версия справа налево (логические CSS-свойства); для арабского, хинди и японского подключены отдельные шрифты Google Fonts; китайская версия внешних шрифтов не грузит и использует системные, потому что в материковом Китае Google Fonts заблокированы; даты форматируются по локали.
- **SEO**: `title`/`description` на каждом языке, canonical, `hreflang` для всех версий, `sitemap.xml`, `robots.txt`, страница 404.

### 2026-09-07 — исправлены кнопки на экране результата

Заказчик заметил, что у кнопок «Отправить по почте», «Скопировать код», «Сохранить в PDF» текст упирается в правую границу. Причина: класс `secondary` использовался и для вторичных кнопок, и для врезки «Вторичный стиль» в отчёте; правило врезки (левая рамка 4px, отступ справа 0) объявлено позже и перебивало отступы кнопок. Дефект был ещё в исходной одноязычной версии.

Сделано: врезка переименована в `substyle`; у кнопок запрещён перенос текста внутри и сжатие как flex-элемента. Проверено в браузере: отступы 20px с обеих сторон, лишней рамки нет.

### 2026-09-07 — китайская версия без Google Fonts; корневая страница без редиректа

Два изменения ради равного качества сайта на всех языках.

1. **Китайская версия (zh) больше не обращается к Google Fonts.** В материковом Китае fonts.googleapis.com заблокирован, и запрос таблицы стилей подвешивал отрисовку страницы до таймаута. Теперь для zh в `FONTS` (build.js) поле `link` пустое, а шрифты системные: PingFang SC (macOS/iOS), Microsoft YaHei (Windows), Noto Sans CJK / Source Han Sans (Android, Linux). В шаблоне три строки подключения шрифтов заменены одним плейсхолдером `__FONTS_HEAD__`, который сборка заполняет только при непустом `link`. Остальные языки не изменились. Ускорение GitHub Pages для Китая через CDN (Cloudflare) не делалось: это отдельное решение, требующее переноса DNS домена на Cloudflare, и оно нужно только если китайский трафик окажется значимым.
2. **Корневая страница без автоперенаправления.** Раньше `/` сразу перебрасывал на язык браузера, что Google не рекомендует: поисковик и часть пользователей не видели других версий. Теперь корневая страница показывает все десять языков, а ранее выбранный или определённый по настройкам браузера язык подсвечивается в списке и выносится наверх кнопкой «Продолжить · Русский» (текст кнопки на самом предлагаемом языке). Без JavaScript остаётся обычный список. Хэш адреса (например, ссылка на результат `#r=…`) передаётся во все ссылки. Снят `noindex` с корневой страницы: она теперь полноценная страница выбора языка, на которую указывает `hreflang="x-default"`. В локали добавлен ключ `ui["root.continue"]` на всех 10 языках.

Проверено локально: корневая страница показывает кнопку и подсветку для языка браузера, ошибок в консоли нет; китайская версия отрисовывается системными шрифтами без единого внешнего запроса шрифтов.

### 2026-09-07 — SEO, этап 3 (шрифты на своём домене)

Шрифты больше не загружаются с Google Fonts: `scripts/fetch-fonts.js` скачал 42 файла woff2 (только нужные начертания и подмножества, 972 КБ) в `src/assets/fonts/`, сборка встраивает `@font-face` только для семейств данного языка и добавляет `preload` двух основных файлов. Японская версия, как и китайская, использует системные шрифты (файлы CJK слишком велики). Выгода: нет запросов к сторонним хостам (в Германии передача IP в Google Fonts считается нарушением GDPR), стабильная загрузка в России и Китае, быстрее первая отрисовка. Тексты плашки cookie и страницы «Конфиденциальность» на 10 языках обновлены: упоминание Google Fonts убрано, добавлено, что шрифты отдаются с самого сайта.

## Что осталось / идеи

- Необязательно: подтвердить домен `disc-test.org` в настройках аккаунта GitHub (Pages → Add a verified domain), чтобы его нельзя было перехватить при смене хостинга.
- **Приём результатов на свой адрес**: заполнить `contactEmail` в `site.config.json` и пересобрать.
