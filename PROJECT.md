# Тест DISC — описание проекта и журнал работ

> Этот файл — краткая «карта» проекта: что это, как устроено, что уже сделано и что осталось.
> Обновляется при каждом изменении проекта. Техническая инструкция по сборке — в [README.md](README.md).

## Что это

Бесплатный онлайн-тест поведенческих стилей DISC (Dominance, Influence, Steadiness, Conscientiousness).
Участник отвечает на 24 блока по 4 утверждения (в каждом отмечает «больше всего похоже на меня» и «меньше всего»),
получает ведущий и вторичный стиль, график, описание сильных сторон, зон роста, мотивации, поведения под стрессом
и рекомендации, как с ним общаться. Всего 16 итоговых профилей (4 «чистых» + 12 сочетаний).

Тест открыт для всех, без регистрации, на 10 языках. Результат считается в браузере и никуда не отправляется.

Ссылка на конкретный результат имеет вид `…/ru/#r=DISC1.…` и открывается на любом языке.

## Как устроено

- **Полностью статический сайт**: HTML + CSS + JS, без сервера и базы данных. Хостинг бесплатный.
- **Один шаблон на все языки**: `src/template.html` содержит вёрстку и логику; тексты подставляются из `src/locales/<язык>.json` при сборке (`node build.js` → `docs/`).
- **Эталон текстов — `src/locales/ru.json`**. Скрипт `scripts/validate-locale.js` проверяет, что каждая локаль структурно совпадает с эталоном (ключи, длины массивов, плейсхолдеры `{n}`, теги `<b>`/`<br>`).
- **Подсчёт результата**: по каждому стилю считается «больше» минус «меньше» (от −24 до +24). Ведущий стиль — максимум; вторичный засчитывается, если он положительный и не меньше 40 % от ведущего (минимум 3). Порядок утверждений в блоках (`BLOCK_KEYS` в шаблоне) менять нельзя: от него зависят коды результатов.
- **Хранение**: прогресс, последний результат и выбранный язык — в `localStorage` браузера участника. Панель администратора (`#admin`) хранит вставленные коды тоже локально, в браузере администратора, и умеет экспортировать таблицу для Excel.
- **Локализация вёрстки**: арабская версия справа налево (логические CSS-свойства); для арабского, хинди, китайского и японского подключены отдельные шрифты Google Fonts; даты форматируются по локали.
- **SEO**: `title`/`description` на каждом языке, canonical, `hreflang` для всех версий, `sitemap.xml`, `robots.txt`, страница 404.

Структура папки:

```
PROJECT.md            этот файл
README.md             как собрать, изменить тексты, добавить язык, подключить домен
site.config.json      адрес сайта, список языков, e-mail для письма с результатом, свой домен
build.js              сборка src → docs
src/template.html     шаблон страницы теста
src/root.html         корневая страница (выбор языка / редирект)
src/404.html          страница «не найдено»
src/locales/*.json    тексты на 10 языках
scripts/              validate-locale.js (проверка локалей), serve.js (локальный просмотр)
docs/                 собранный сайт — то, что публикуется
disc-test/index.html  исходная одноязычная версия (история)
```

## Журнал работ

### 2026-09-06 … 2026-09-07 — публикация мультиязычной версии

Исходное состояние: один файл `disc-test/index.html` на русском, с зашитым личным e-mail для отправки результатов.

Сделано:

1. Тексты вынесены из кода в `src/locales/ru.json`; приложение переписано в шаблон, который берёт строки из локали. Логика теста, подсчёт и формат кодов результата не менялись — старые коды совместимы.
2. Написаны локали на 9 языков (en, es, zh, ar, pt, fr, de, ja, hi). Переводы выполнены нейросетью, проверены скриптом на структуру и вычитаны на естественность; носителями не проверялись.
3. Добавлен скрипт сборки `build.js`: генерирует по странице на язык, корневую страницу с автоопределением языка, `sitemap.xml`, `robots.txt`, `404.html`, `.nojekyll`; при наличии `customDomain` — `CNAME`.
4. Вёрстка адаптирована под RTL (арабский) и под шрифты для деванагари, китайского и японского; в шапке и подвале добавлен переключатель языков.
5. Изменена схема доставки результата для публичного сайта: добавлена кнопка «Скопировать ссылку» (ссылка `#r=код` открывает отчёт на любом языке); личный e-mail из кода убран, кнопка «Отправить по почте» открывает письмо без адресата (адрес можно задать в `site.config.json`); панель администратора сохранена.
6. Добавлена строка о приватности: ответы и результат не покидают браузер.
7. Проверено в браузере: вступление, прохождение (авто-переход между блоками), отчёт, ссылка на результат на другом языке, админ-панель (разбор кода из вставленного текста), мобильная вёрстка, арабская RTL-версия, живой сайт.
8. Создан публичный репозиторий `Man-You-Can/disc-test`, включён GitHub Pages (`main:/docs`), все 10 языков доступны по HTTPS.
9. Написаны `README.md` (инструкции), `package.json` (`npm run build / validate / serve / deploy`), этот `PROJECT.md`.

Особенности процесса: три перевода (es, fr) были дописаны вручную после сбоя автоматических переводчиков по лимиту сессии; хинди автоматический переводчик успел закончить, файл прошёл проверку.

### 2026-09-07 — флаги в переключателе языков

По просьбе заказчика к каждому языку добавлен флаг. Нативный `<select>` не умеет показывать картинки, а эмодзи-флаги не отображаются на Windows, поэтому:

1. Переключатель в шапке заменён на собственный выпадающий список (кнопка + список): флаг и название языка, галочка у текущего, поддержка клавиатуры (стрелки, Home/End, Enter, Escape), закрытие по клику вне списка, зеркальное выравнивание в арабской версии.
2. Флаги нарисованы как упрощённые встроенные SVG (спрайт `<symbol>` генерируется в `build.js`, функция `FLAGS`), поэтому выглядят одинаково на всех платформах. Соответствие: English — Великобритания, Русский — Россия, Español — Испания, 简体中文 — Китай, العربية — Саудовская Аравия, Português — Бразилия, Français — Франция, Deutsch — Германия, 日本語 — Япония, हिन्दी — Индия.
3. Флаги добавлены также к ссылкам на языки в подвале и на корневой странице выбора языка.
4. Переход между языками по-прежнему сохраняет открытый экран (`#r=…`, `#admin`) и запоминает выбор.

## Что осталось / идеи

- **Вычитка переводов носителями** — в первую очередь 24 блока утверждений, от них зависит точность результата.
- **Свой домен**: указать `siteUrl` и `customDomain` в `site.config.json`, пересобрать, добавить DNS-записи и домен в настройках Pages (шаги в README).
- **Приём результатов на свой адрес**: заполнить `contactEmail` в `site.config.json` и пересобрать.
- Необязательно: картинка для предпросмотра ссылок в мессенджерах (og:image), аналитика посещений, серверное сохранение результатов (потребует бэкенд).
